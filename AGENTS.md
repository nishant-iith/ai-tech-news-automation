# Agent instructions for this repository

## Remotion
- Read `.agents/skills/cinematic-camera/SKILL.md` and `.agents/skills/article-highlights/SKILL.md` before modifying Remotion visuals.
- Follow official [Remotion skills](https://github.com/remotion-dev/skills), especially remotion-best-practices, markup and rendering.
- Preserve the current approved project palette and video format, unless the user asks to change them.
- A scene should have causal visual continuity, not unrelated title slides. Use one camera timeline, readable text, restrained flat colours and source-accurate editorial content.
- Do not fabricate real article screenshots, publishers, quotes, product UIs, dates or metrics. Use clearly labeled educational demo copy if no real sources are supplied.
- Before delivery: typecheck where possible, render to MP4, inspect still frames at opening/middle/end, verify output duration and audio.
- The sample must remain a non-publishing manual review prototype.
