# AI Tech News Automation

Cloud-based prototype for collecting top tech news, creating natural English/Hinglish scripts, and generating animated short-form videos using Remotion and GitHub Actions.

## Goals
- Discover and verify important tech news from the previous 24 hours.
- Select five high-impact stories for a global or Indian audience.
- Produce an engaging vertical video with motion graphics, subtitles, and voiceover.
- Keep initial automation within free tiers; review quality before publishing.

## Status

Initial GitHub write-access test. Video generation and social publishing are not yet configured or enabled.

Do not commit API keys or credentials to this public repository.
